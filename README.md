Code developed to operate a Mueller Matrix Microscope, May - August, 2026. 

Mueller matrices are a powerful tool for demonstrating how thin film materials
affect the polarization states as light passes through the material. 

The programs are designed to be run in conjunction with an IDS camera, and assumes
an optical setup described in the attached article by Oriol Arteaga, page 6.

All work done under the supervision of Professor Richard Douglas Robinson, Duffield 
College of Engineering, Cornell University.
